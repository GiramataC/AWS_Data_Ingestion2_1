DEVIATION FROM LAB SPEC
--------------------------------------------------------------------
Instance type: lab spec calls for t2.micro. This account's AWS
Organizations SCP (p-yb2lfviw) explicitly denies ec2:RunInstances for
the t2 family. Confirmed via iterative --dry-run testing (subnet, AMI,
and instance type were each isolated) - t2.micro is denied regardless
of subnet/AMI, t3.micro is allowed. Used t3.micro instead; no other
part of the pipeline is affected since DataSync's source and
destination are both S3 (the EC2 box is only a stand-in for "on-prem"
and isn't in the data path).
